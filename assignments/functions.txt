Python is neither purely call by value nor purely call by reference. Python uses a mechanism commonly called Call by Object Reference, Call by Sharing, or Pass by Assignment.
Let's understand this with examples, especially if you are familiar with Java.
1. First, understand the three concepts
- Call by Value: A function receives a copy of the value. Reassigning the parameter does not change the caller's variable.
- Call by Reference: A function receives access to the caller's variable itself, so it can change what that variable refers to.
- Call by Object Sharing (Python): A function parameter refers to the same object as the argument. Mutating a mutable object can affect the caller's object, but reassigning the parameter does not reassign the caller's variable.

reduce() is a function from the functools module that applies a function cumulatively to the items of a sequence (like a list)
 from left to right, reducing it to a single value.

reduce(function, iterable[, initializer])

function – a function of two arguments (can be lambda).

iterable – a sequence (list, tuple, etc.) whose elements will be reduced.

initializer – (optional) a starting value for the accumulator.

15

Step 1: add(1,2) => 3
Step 2: add(3,3) => 6
Step 3: add(6,4) => 10
Step 4: add(10,5) => 15

Instead of defining a separate function like add(), you can use a lambda directly:

15

x stores the intermediate result, and y is the next element in the list.

reduce() applies the lambda cumulatively across the list.

=>limitations of lamda Functions in Python:---
===========================


Lambda functions are designed for very small, temporary logic —
so Python intentionally keeps them restricted.

1️. Only One Expression Allowed

Lambda can contain only a single expression (one line of logic).

✔ Allowed

lambda x: x*x


❌ Not allowed

lambda x:
    y = x + 2
    return y


You cannot write:

multiple statements

multiple lines

2️.No Assignments Inside Lambda

You cannot assign variables inside a lambda.

❌ Wrong

lambda x: y = x + 2


Because assignment (=) is a statement, not an expression.

3️.No Loops or Complex Logic

You cannot write loops like for, while.

❌ Not allowed

lambda x: 
    for i in range(x):
        print(i)


Lambda is only for quick calculations.

4️.No Statements (print, pass, raise, etc.)

Lambda only supports expressions — not statements.

❌ Not allowed

lambda x: print(x)
lambda x: raise Exception("error")


(You can technically call print() in modern Python, but lambda should not be used for such logic — it's bad practice.)

5️.Hard to Read for Complex Conditions

Large lambda becomes unreadable:

❌ Bad practice

lambda x: x**2 if x>0 else -x if x<-10 else x+5 if x<100 else x/2

Cannot Contain Multiple Returns

Only one automatic return exists.

Not Reusable (No Name / No Debugging)

Cannot easily reuse

Hard to debug in stack trace

Bad for large programs

=>Recursion:---
=============


Recursion is a programming technique in which a function calls itself to solve a problem.

Instead of using loops (for, while), the function repeatedly breaks the problem into smaller sub-problems of the same type until 
it reaches a stopping condition.


->Every recursive function MUST have 2 parts:

Base Case (Stopping Condition)
Prevents infinite calling

Recursive Case (Self Call)
Function calls itself with smaller input


syntax:--
def function_name(parameters):

    if base_condition:
        return result

    return function_name(smaller_input)
If the base case is missing → ❌ Infinite recursion → Program crash (Stack Overflow)


Example 1 — Factorial (Most Important Example)
Mathematical Definition
5! = 5 × 4 × 3 × 2 × 1
0! = 1

n! = n × (n-1)!

ex-
def factorial(n):

    # Base Case
    if n == 0 or n == 1:
        return 1

    # Recursive Call
    return n * factorial(n-1)


print(factorial(5))

o/p
120

ex-2  Sum of Numbers

sum(5) = 5 + 4 + 3 + 2 + 1

    if n == 0:
        return 0
    return n + sum_n(n-1)

Fibonacci Series
def fibonacci(n):

    # Base Cases
    if n == 0:
        return 0
    elif n == 1:
        return 1

    # Recursive Case
    return fibonacci(n-1) + fibonacci(n-2)


# Print 10 Fibonacci numbers
for i in range(10):
    print(fibonacci(i), end=" ")

Step-by-Step Working (Example: fibonacci(5))
fibonacci(5)
= fibonacci(4) + fibonacci(3)

fibonacci(4)
= fibonacci(3) + fibonacci(2)

fibonacci(3)
= fibonacci(2) + fibonacci(1)

fibonacci(2)
= fibonacci(1) + fibonacci(0)

Now base cases:
fibonacci(1) = 1
fibonacci(0) = 0
Then values return back (Backtracking):

fibonacci(2) = 1 + 0 = 1
fibonacci(3) = 1 + 1 = 2
fibonacci(4) = 2 + 1 = 3
fibonacci(5) = 3 + 2 = 5

                fib(5)

      /      \            /      \
   fib(3)   fib(2)    fib(2)   fib(1)

=>What is nonlocal?
==================

In Python, nonlocal keyword is used inside a nested function to modify a variable that belongs to the enclosing (outer) function,
 but not the global scope.

👉 It tells Python:

“Don’t create a new local variable — use the variable from the nearest outer function.”

ex-5- nonlocal
def outer():
    x = 10
    
    def inner():
        nonlocal x;
        x=100
        print("Value of x is:", x)
    
    inner()
    print("now value of x is in outer",x)

outer()
o/p
Value of x is: 100
now value of x is in outer 100

NOTE:--
Why Do We Need nonlocal?

Python follows LEGB rule for variable lookup:

L → Local

E → Enclosing

G → Global

B → Built-in

By default:

If you assign a value inside a function → Python treats it as local variable

So it does NOT modify the outer function variable unless we use nonlocal


Important Rules of nonlocal:--
------------------------------

It is used only inside nested functions.

The variable must already exist in the enclosing function.

It cannot refer to global variables.

It works only with nearest enclosing scope.

=>What is a Closure?=>
=====================
A closure is a function object that remembers values from its enclosing (outer) function scope, even after the outer function has finished execution.

In simpler words:
A closure “closes over” variables from the outer function so they stay accessible later.

Key points:

A closure is created when a nested function references a variable from the outer function.

The outer function returns the inner function.

The inner function can be called later, and it will remember the outer function’s variables.

ex-1
def greet(name):
    message = f"Hello {name}!"
    
    def display_message():
        print(message)  # inner function uses outer variable
    
    return display_message

# Create closure
greeting = greet("Ajay")

# Call the inner function later
greeting()


o/p
Hello Ajay!
NOTE:--
greet("Ajay") returns display_message function.

Even though greet has finished executing, display_message still remembers message.


ex-2  Closure with Modifiable Outer Variable using nonlocal
def counter():
    count = 0
    
    def increment():
        nonlocal count
        count += 1
        return count
    
    return increment

# Create closure
c = counter()

print(c())  # 1
print(c())  # 2
print(c())  # 3

=>What is a Decorator?

A decorator in Python is a function that modifies the behavior of another function or method. 
In simple terms, it “wraps” another function to add extra functionality without modifying the original function’s code.

Reduces repetitive code and separates concerns.

    def wrapper():
        print("Before calling the function")
        func()  # call the original function
        print("After calling the function")
    return wrapper

@my_decorator
def say_hello():
    print("Hello!")


say_hello()

o/p

Hello!
After calling the function


NOTE:--
The @my_decorator is equivalent to:

say_hello = my_decorator(say_hello)


Here’s what happens internally:

Python sees @my_decorator.

It passes the original say_hello function as the argument func to my_decorator.

my_decorator creates the wrapper function that calls say_hello() inside it.

my_decorator returns wrapper, and now the name say_hello points to wrapper.

So after decoration:

say_hello  --> wrapper function (inside my_decorator)
The original say_hello is now wrapped inside wrapper.

->Calling the decorated function
say_hello()


Remember, say_hello now points to wrapper.

So calling say_hello() actually executes the wrapper function:

 you from passing a string or floating-point number to the function at runtime.

=>=Higher Order Functions in Python=>
========================================
In Python, Higher Order Functions (HOFs) play an important role in functional programming and allow for writing more modular, reusable and readable code. A Higher-Order Function is a function that either:

Takes another function as an argument
Returns a function as a result

ex-1
def greet(func): # higher-order function 
    return func("Hello")

def uppercase(text): # function to be passed
    return text.upper()

print(greet(uppercase))

o/p
HELLO

Explanation: greet(func) is a higher-order function as it takes another function as an argument. 
uppercase(text) converts text to uppercase. Calling greet(uppercase) passes "Hello" to uppercase, resulting in "HELLO".


Examples of Higher Order Functions:---


Example 1 : Passing a functions as an arguments
A function can be passed as an argument to another function, enabling dynamic behavior.


def apply(func, x): # higher order function
    return func(x)

def square(n): # function to be passed
    return n * n

print(apply(square, 5))
