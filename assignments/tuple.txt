Python Tuples:-
=======
A tuple in python is similar to a list, very similar to brothers but the difference is that we cannot change the elements of a tuple once it is assigned whereas we can change/edit the elements of a list.

in short, a tuple is an immutable list. A tuple cannot be changed in any way once it is created.

Core Characteristics —

· Ordered — order matters just like the list. means 1,2,3 != 3,2,1

· Unchangeable — Once created, you cannot change it, it is immutable.

· Allows duplicate — we can put multiple duplicate values, there is no restriction.

Memory Allocation in Tuples:--
=============================
Tuples, unlike lists are immutable, meaning their contents cannot be changed once they are created. 
This immutability provides certain optimizations in terms of memory management.

Fixed Size: Once a tuple is created, its size is fixed which means no resizing is required.
Lower Memory Overhead: Since tuples are immutable, Python can allocate memory more efficiently.
Memory Efficiency: Tuples are more memory efficient when dealing with a large amount of data that doesn't 
require modification. The reduced overhead makes tuples faster in terms of memory access and iteration.


NOTE:--
check diagram in images notes..
->Memory allocated for the tuple corresponds exactly to its size (4 elements). 
No extra memory is allocated for future growth because tuples are immutable.

->When a new element ('now') is added, a new tuple (Tnew) is created in memory. 
This tuple contains all the elements from the old tuple (T1) plus the new element. The original tuple (T1) remains unchanged.
This process demonstrates that tuples require new memory allocation whenever their size changes.

ex-
import sys
a = ('Learn', 'Python', 'with', 'GFG')

# Checking memory usage of the tuple
print("Memory size of tuple:", sys.getsizeof(a)) 

o/p
Memory size of tuple: 72

Explanation
----------

Tuple stores only references to objects, not the objects themselves.
Your tuple: ('Learn', 'Python', 'with', 'GFG') → 4 elements → 4 pointers.

Memory = tuple overhead + pointers

Tuple overhead (object header) ≈ 48 bytes

4 pointers × 6 bytes (optimized for small tuples in your Python version) ≈ 24 bytes

Total = 48 + 24 = 72 bytes

sys.getsizeof() returns the shallow size (tuple container only), not the memory of the strings inside.


example with list
import sys

# Creating a list with same elements
a = ['Learn', 'Python', 'with', 'GFG']

# Checking memory usage of the list
print("Memory size of list:", sys.getsizeof(a))

o/p
Memory size of list: 88

Why list memory is bigger (88 bytes)-
-------------------

Lists are mutable

Python allocates extra memory for lists to allow dynamic resizing (appending elements).

This extra space is called overallocation buffer.



=>differences between list and tuple in Python:=
============================================
1. Mutability:
List: Lists are mutable,
Tuple: Tuples are immutable,

2.Immutability Advantages:-
Memory efficient: Since tuples are immutable, Python can optimize memory allocation. They consume less memory than lists.

Faster: Tuple operations are generally faster than list operations because no dynamic resizing is needed.

Hashable: Tuples (if all elements are immutable) can be used as dictionary keys or set elements, unlike lists.

3.Methods Available:-
List: Has many built-in methods like append(), extend(), insert(), pop(), remove(), clear(), reverse(), sort().

Tuple: Very limited methods: 

Reason: Because tuple is immutable, it cannot modify itself, so no need for modification methods.

4.Use Cases:-
List:

Used when you need dynamic, changeable data.

Examples: shopping cart, task list, dynamic records.

Tuple:

Used when data is fixed or constant.

Examples: coordinates (x, y), RGB color (255, 0, 0), database record, function multiple return values.

5. Performance and Memory
===========================
List:

Mutable → Python allocates extra memory for dynamic growth (overallocation).

Slightly slower than tuples.

Tuple:

Immutable → exact memory allocation, smaller and faster.

6.
Iteration and Access

Both support indexing, slicing, and iteration.

Accessing elements is the same for lists and tuples:

7.Nesting

Both lists and tuples can be nested, i.e., contain other lists/tuples as elements.

Important: The tuple itself is immutable, but if it contains a mutable object (like a list), that object can still be modified.

8.
 Packing and Unpacking

Both support packing and unpacking.

# Tuple
t = 1, 2, 3
a, b, c = t

# List
l = [1, 2, 3]
x, y, z = l


You can also do extended unpacking with both:

a, *b, c = (1,2,3,4,5)

9.
Function Return Values

Functions in Python return tuples by default when multiple values are returned:

def calc(a,b):
    return a+b, a-b  # returns a tuple

res = calc(5,2)
print(res)  # (7, 3)

10.
 Hashability

Tuple: Can be hashable if all elements are immutable → can be dictionary keys.

List: Not hashable → cannot be dictionary keys or set elements.


11.
Copying Behavior

List: Can be copied by reference or using .copy() to create a new object.

Tuple: Copying just creates a reference, since it is immutable, there’s no difference between original and copy.

NamedTuple:=
==========	
A Named Tuple is a special type of tuple in Python that allows you to access elements using names instead of index positions.

Normally in a tuple, you access data using index numbers. But in named tuples, each element has a field name, which makes the code more readable, structured, and meaningful.

Named tuples are defined in Python using the collections module.
->Normal tuples create confusion when data contains multiple fields.

How to Create Named Tuple:--
------------------------------
syntax:--
from collections import namedtuple
TupleName = namedtuple("TupleName", ["field1", "field2", "field3"])

ex-1
from collections import namedtuple

Student = namedtuple("Student", ["name", "age", "city"])

s1 = Student("Ajay", 25, "Bhopal")

print(s1.name)
print(s1.age)
print(s1.city)

o/p
Ajay
25
Bhopal

detail:--

3._replace():-
==============
Creates a new object with updated value.

4._make():--
===========

_make() is a class method available in namedtuple.

Purpose: Create a namedtuple instance from an iterable (like list, tuple, etc.) instead of passing individual values.

Think of it as a shortcut to convert a list/tuple into a namedtuple object.


ex-1
from collections import namedtuple

# Create namedtuple class
Student = namedtuple("Student", ["name", "age", "city"])

# Data in a list
data = ["Ajay", 25, "Bhopal"]

# Create namedtuple object using _make()
s1 = Student._make(data)

# Access fields
print(s1.name)  # Ajay
print(s1.age)   # 25
print(s1.city)  # Bhopal

o/p
Ajay
25
Bhopal

NOte:
Number of elements in iterable must match the number of fields in the namedtuple.


ex-2:-- Example with Tuple
from collections import namedtuple

# Create namedtuple class
Student = namedtuple("Student", ["name", "age", "city"])
info = ("Ravi", 22, "Delhi")
s2 = Student._make(info)
print(s2)
